CVAT SAM 3 Segment

Click-to-segment in CVAT using your own SAM 3 Nuclio function.

Model endpoint

Must accept POST with {"image": "<base64>", "pos_points": [[x,y]], "neg_points": [], "obj_bbox": null} and return {"shapes": [{"type": "mask", "points": [...]}]} — this is what the CVAT pth-facebookresearch-sam3 interactor already does.

CVAT sites

    The extension only injects into the sites listed here.

    Usage

    Open a job in CVAT, press Alt+S (or flip the switch in the panel), then click an object. Shift+click adds a negative point, drag in Box mode to prompt with a rectangle.

    Masks are written straight through the CVAT API, so the annotator has to be reloaded to show them — use Save to flush CVAT's own unsaved edits, then Reload view in the panel when you are done.
